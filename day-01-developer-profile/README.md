# Day 1 — Developer Profile Card

**Topic:** Introduction to Python (setup, first script, `print()`, comments)

## What it does
Prints a profile card: the intro you'll paste into your GitHub bio, job
applications, and dev communities. It is the *honest* Day 1 project:
**no imports, no logic, no if/else** — just `print()` and writting comments and running a python scripts

## Why is there no solution.py here?
Day 1 is the "hello world" of the series  the lesson IS the file.
Write it, run it, edit it, make it yours. **From Day 2 onward**, every
project follows the 3-file pattern (spec + starter + solution).

## How to run
```bash
cd day-01-developer-profile
python3 main.py
```

## What I learned
- Running a script with `python3 main.py`
- `print()` writes text to the terminal
- Comments (`#`) are for humans — Python ignores them
- Editing code in nano (`Ctrl+O` save, `Ctrl+X` exit)
- A sneak peek at tomorrow's topic: variables
